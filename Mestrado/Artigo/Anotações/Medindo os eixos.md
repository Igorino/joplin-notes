# Eixo 1: Custo / Escalabilidade 
> Propriedade virada pro designer

*Quanto o algoritmo onera? Dá pra rodar vários "cérebros" ao mesmo tempo?*
*É uma propriedade do sistema, medida objetiva.*

**Como medir**: tempo de decisão, CPU/memória, custo por frame no pior caso, etc.

# Eixo 2: Controlabilidade / Autoria 
> Propriedade virada pro designer. "Auditar"

*Dá pra editar parâmetros sem quebrar a lógica? É fácil e intuitivo fazer essa edição? Restringir o escopo de ações? Auditar as decisões?*

**Como medir:** [Expressive Range Analysis](https://dl.acm.org/doi/10.1145/1814256.1814260), [dimensão de "authorial intent" de Riedl](https://onlinelibrary.wiley.com/doi/epdf/10.1609/aimag.v34i1.2449).

# Eixo 3: Emergência 
> Propriedade do sistema

*O quão não-scriptado / variado / novo é o espaço de comportamento que a arquitetura produz?*

**Como medir:** [Expressive Range Analysis](https://dl.acm.org/doi/10.1145/1814256.1814260), [Tension Space Analysis for Emergent Narrative](https://www.researchgate.net/publication/340884241_Tension_Space_Analysis_for_Emergent_Narrative), [On the Evaluation of Procedural Level Generation Systems](https://arxiv.org/abs/2404.18657)

# Eixo 4: Believability 
> Propriedade de percepção do jogador

*O jogador acha o NPC crível/vivo? Parece ter um comportamento "natural" e "realista"? A emergência do sistema se traduz em percepção?*

**Como medir**: [Virtual Agent Believability Questionaire](https://www.researchgate.net/publication/376266175_Developing_a_Scale_for_Measuring_the_Believability_of_Virtual_Agents), [Development and Validation of the Companion Design Scale](https://www.researchgate.net/publication/382231173_What_does_the_perfect_Companion_in_Games_look_like_Development_and_Validation_of_the_Companion_Design_Scale)
